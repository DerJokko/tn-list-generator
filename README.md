# TN-Listen Generator

Diese Seite wandelt Google-Anmeldungen, die als TSV-Datei exportiert wurden, in eine strukturierte Teilnehmerliste (TN-Liste) für den PDF-Export um.

## So nutzt du die Seite

1. Datei laden
   - Öffne die Seite im Browser.
   - Klicke auf „Datei wählen“ und lade deine TSV-Datei aus Google Forms bzw. Google Sheets hoch.

2. Spalten konfigurieren
   - Wähle die Spalten aus, die in der TN-Liste erscheinen sollen.
   - Markiere eine Spalte als Gruppierung, damit die Teilnehmer automatisch nach Sipen sortiert werden.
   - Zähler: Bei so makierten Spalten wird die Anzahl jeder verschiedenen Antwort unter die Tabelle geschireben, zB "4x Vegan, 8x Vegetarisch" usw.
   - Sonstiges: Alle als Sonstiges makierten Spalten werden in einer Spalte "Sonstiges" mit Kommata getrennt zusammengefasst.

3. Teilnehmer prüfen
   - In der Vorschau kannst du Zeilen mit „SiFü“ markieren.
   - Die Auswahl wirkt sich auf die Darstellung und den PDF-Export aus.
   - Über die Hauptgruppe kannst du eine besondere Gruppe zuerst anzeigen lassen, zB Ranger/Rover. Auswahl unter der Spaltenauswahl nach Wahl der Sippenspalte.

4. Titel und PDF vorbereiten
   - Gib im Bereich „Titel für PDF / Dateiname“ einen passenden Namen ein.

5. Als PDF exportieren
   - Klicke auf „Als PDF exportieren“.
   - Die Datei wird als PDF heruntergeladen und kann direkt weiterverarbeitet oder ausgedruckt werden.

6. Speichern
   - Es ist möglich, den aktuellen Bearbeitungsstand lokal zu speichern und einen lokalen Speicherstand für einen anderen Computer als .json zu exportieren.
   - Zum Laden eines Speicherstandes den Stand aus wählen oder importieren.

## Hinweis

Die TSV-Datei sollte als Tab-getrennte Textdatei vorliegen. Die Spaltennamen aus Google-Anmeldungen werden automatisch übernommen.
